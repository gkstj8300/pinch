# [설계서] 단기 자투리 알바 매칭 플랫폼: 핀치 (PINCH)

본 문서는 일본의 '타이미(Timee)' 모델을 벤치마킹하여 한국 시장 환경에 최적화한 초단기 구인구직 플랫폼 **'핀치(PINCH)'**의 개발 설계 사양을 담고 있습니다.

---

## 1. 프로젝트 개요
* **서비스 명:** 핀치 (PINCH) - "필요한 순간, 한 꼬집의 시간을 채우다"
* **핵심 가치:** * **No Resume, No Interview:** 프로필 기반 즉시 매칭
    * **Instant Pay:** 업무 종료 후 즉시 급여 정산
    * **Trust Based:** 상호 평가를 통한 신뢰도 확보
* **주요 타겟:** 대학생, N잡러, 파트타임 인력이 급히 필요한 자영업자 및 기업

---

## 2. 시스템 아키텍처 (System Architecture)

### 2.1 기술 스택
* **Frontend:**
    * Worker App: Flutter 또는 React Native (iOS/Android 통합 개발)
    * Client Web/App: React.js (관리자 페이지 및 사업주용 웹)
* **Backend:**
    * API Server: Node.js (NestJS) - 빠른 개발 속도 및 비동기 처리 최적화
    * Database: PostgreSQL (주요 데이터), Redis (캐싱 및 실시간 알림)
* **Infrastructure:**
    * Cloud: AWS (EC2, S3, RDS, Lambda)
    * CI/CD: GitHub Actions, Docker
* **External Services:**
    * 본인인증: NICE/다날 본인확인 서비스
    * 결제/정산: 포트원(PortOne) API 연동
    * 지도: 카카오맵 API

---

## 3. 핵심 기능 상세 (Core Features)

### 3.1 워커(Worker) 앱
1. **프로필 기반 가입:** 이력서 대신 과거 근무 이력, 별점, 보유 자격증 위주 구성.
2. **위치 기반 공고 탐색:** 지도 UI를 통해 내 주변 실시간 알바 확인.
3. **매칭 시스템:** 조건 충족 시 '지원하기' 클릭 즉시 확정 (선착순 모델).
4. **근태 관리:** * GPS 기반 현장 도착 확인.
    * 앱 내 QR 코드를 활용한 출퇴근(Check-in/out) 인증.
5. **디지털 지갑:** 업무 승인 후 포인트 즉시 적립 및 본인 계좌 출금 기능.

### 3.2 클라이언트(Client) 웹/앱
1. **간편 공고 등록:** 업무 내용, 시간, 장소, 시급 설정 및 템플릿 저장.
2. **실시간 인력 현황:** 출근 예정자 및 현재 근무자 리스트 모니터링.
3. **업무 승인 및 평가:** 근무 종료 후 원클릭 승인 및 워커 별점 평가.
4. **자동 세무 처리:** 일용직 신고를 위한 데이터 엑셀 추출 및 세무 대행 연동.

## 4. 데이터베이스 설계 (Data Schema)

### 주요 테이블 구조
* **User (사용자):** id, phone, name, profile_img, role(worker/client), rating_avg
* **Job (공고):** id, client_id, category, title, content, location(point), start_at, end_at, wage
* **Matching (매칭):** id, job_id, worker_id, status(matching, check_in, completed, noshow)
* **Wallet (지갑):** id, user_id, balance, transaction_history
* **Review (리뷰):** id, target_id, writer_id, score, comment

---

## 5. 한국 시장 특화 전략 (K-Localization)

1. **법적 준수 (Labor Compliance):**
    * 주휴수당 계산기 및 최저임금 가이드라인 적용.
    * 4대 보험/원천세(3.3%) 자동 계산 시스템.
2. **신뢰 지수 (Pinch Score):**
    * 단순히 별점뿐만 아니라 '지각 횟수', '취소율'을 반영한 독자적인 신뢰 지수 운영.
    * 노쇼(No-show) 발생 시 강력한 이용 정지 정책 적용.
3. **커뮤니티 요소:**
    * '동네 알바 후기' 등 워커들 간의 정보 공유 게시판 운영.

## 6. 개발 로드맵 (Roadmap)

1. **Step 1 (MVP 개발):** * 핵심 매칭 프로세스 및 QR 출퇴근 기능 구현.
    * 수동 정산 시스템으로 시작하여 BM 검증.
2. **Step 2 (자동화 및 고도화):**
    * PG사 연동을 통한 실시간 정산 자동화.
    * 푸시 알림 최적화 및 타겟 마케팅 기능 추가.
3. **Step 3 (확장):**
    * AI 기반 맞춤형 알바 추천 알고리즘 도입.
    * B2B 대규모 인력 파견 관리 솔루션 출시.

## 7. 기술적 고려사항
* **Race Condition 방지:** 선착순 매칭 시 발생하는 동시성 문제를 Redis 분산 락(Distributed Lock)으로 해결.
* **대량 알림 처리:** 공고 등록 시 수만 명에게 발송되는 푸시 알림의 부하 분산을 위해 메시지 큐(AWS SQS) 사용.
