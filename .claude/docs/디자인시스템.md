## 2. 채택 결정 사항 (Decision Log)

| # | 결정 | 근거 |
|---|---|---|
| **D1** | Identity Color 메인 = **Pink `#fa2454`** | Timee 톤(긴급·즉시성·열정) — 초단기 알바의 "지금 필요한 한 꼬집" 가치와 정합. 알바몬·잡코리아와 차별화. |
| **D2** | 그린은 **success(긍정)** 의미 한 가지로만 사용 | Identity 그린(`#1ba74e`) 은 Pink 와 의미 충돌 → 제거. Support success (`#1eb96e`) 만 유지. |
| **D3** | 토큰 네이밍 = **베어 키 (bare key)** 단일 사용 | Figma 원본의 `Color-X/color-x-*` 프리픽스 키와 `color-*` 베어 키가 동일 의미로 중복됨 → 베어 키 하나로 일원화 (단, 의미·값은 보존). |
| **D4** | Gray 30/40/50 = **보강 (재배치 + 보간)** | 원본에 0/10/20/60/70/80/90 만 존재하여 중간 위계 공백 — 기존 `#cfd3d8`·`#b4b9be` 를 단계 명으로 승격하고 50은 보간으로 신설. |

## 3. Brand Identity Color (Pink 계열)

```
Primary       #fa2454   메인 CTA, 강조 텍스트, 강조 보더
Primary Hover #ef0035   버튼 호버, "강조 더 강하게"
Sub           #ffd1dc   배경 강조 (배너·선택된 카드)
```

### 사용 가이드

| 토큰 | 용도 |
|---|---|
| `color-button-primary` | 주 CTA 버튼 배경 (지원하기 / 등록 / 승인) |
| `color-button-primary-hover` | 위의 hover/pressed 상태 |
| `color-text-identity` | 강조 텍스트 (긴 본문 속 핵심 키워드) |
| `color-text-identity-strong` | 더 강한 강조 (가격, 시급 등 수치) |
| `color-background-identity` | 강조 배경 (오늘의 추천 배너) |
| `color-background-identity-sub` | 약한 강조 배경 (선택된 칩) |
| `color-border-identity` | 강조 테두리 (active 탭 underline 등) |

### 사용하지 말아야 할 곳

- 본문 텍스트 색 (가독성 ↓)
- 비활성 상태 (의미 혼동)
- 4개 이상의 인접 영역에 동시 사용 (시각 피로)

## 4. 최종 Color Tokens (베어 키)

### 4.1 Gray Scale (Cool, 9단계 완성)

| 토큰 | HEX | 출처 | 권장 용도 |
|---|---|---|---|
| `light/gray/0` | `#fdfdfd` | 원본 | 페이지 배경 |
| `light/gray/10` | `#e9edf0` | 원본 | 카드 배경, 보조 테두리 |
| `light/gray/20` | `#e0e4e8` | 원본 | 카드 보더 |
| `light/gray/30` | `#cfd3d8` | **보강** (기존 `tertiary-hover` 승격) | 인풋 비활성 배경, 구분선 |
| `light/gray/40` | `#b4b9be` | **보강** (기존 `text-quaternary` 승격) | 비활성 텍스트, placeholder |
| `light/gray/50` | `#8e949a` | **신규** (보간) | 보조 아이콘, 비활성 보더 |
| `light/gray/60` | `#757b82` | 원본 | tertiary 텍스트, helper |
| `light/gray/70` | `#4a4f55` | 원본 | secondary 텍스트, 기본 보더 |
| `light/gray/80` | `#2e3236` | 원본 | secondary 버튼 |
| `light/gray/90` | `#202225` | 원본 | primary 텍스트 |

### 4.2 Semantic Tokens

```
Background:   primary #fdfdfd  →  secondary #f3f5f7  →  tertiary #e9edf0
Text:         primary #202225  →  secondary #4a4f55  →  tertiary #757b82  →  quaternary #b4b9be  →  primary-inverse #fdfdfd
Border:       primary #4a4f55  →  secondary #b4b9be  →  tertiary #e0e4e8
```

### 4.3 Button

```
primary           #fa2454      ↔ hover #ef0035
secondary         #2e3236      ↔ hover #4a4f55
tertiary          #e9edf0      ↔ hover #cfd3d8
white             #fdfdfd      ↔ hover #e9edf0
```

## 5. Typography (Pretendard, 13단계)

모두 `font-family: "Pretendard"`, `line-height: 1.4`, `letter-spacing: -0.5`.

| 토큰 | size | weight | 권장 용도 |
|---|---|---|---|
| `heading/00` | 24 | 700 Bold | 페이지 타이틀 (홈 헤더, 마이페이지) |
| `heading/01` | 20 | 600 SemiBold | 섹션 타이틀 |
| `heading/02` | 18 | 700 Bold | 카드 강조 타이틀 |
| `heading/03` | 18 | 600 SemiBold | 카드 일반 타이틀 |
| `heading/04` | 16 | 700 Bold | 강조 라벨 |
| `heading/05` | 16 | 600 SemiBold | 일반 라벨 |
| `body/01` | 14 | 700 Bold | 본문 최강 강조 |
| `body/02` | 14 | 600 SemiBold | 본문 강조 |
| `body/03` | 14 | 500 Medium | 본문 보통 |
| `body/04` | 14 | 400 Regular | 본문 기본 |
| `caption/01` | 12 | 600 SemiBold | 캡션 강조 (배지 텍스트) |
| `caption/02` | 12 | 500 Medium | 캡션 보통 |
| `caption/03` | 12 | 400 Regular | 캡션 기본 (helper text) |

### Pretendard 적용 방법

- **Web**: `pnpm add pretendard` → `import 'pretendard/dist/web/static/pretendard.css'`
- **RN/Expo**: `expo-font` 로 `Pretendard-Bold.otf`, `Pretendard-SemiBold.otf`, `Pretendard-Medium.otf`, `Pretendard-Regular.otf` 4종 로드

## 11. 의도적으로 제외된 것

- **Identity 그린** (`#1ba74e`) — D2 에 따라 전 영역 제거
- **`Color-X/...` 프리픽스 키 전체** — D3 에 따라 베어 키로 일원화 (의미·값은 모두 보존됨)
- **이중 토큰 명명** (예: `Text/color-text-primary` 와 `color-text-primary` 동시 존재) — 베어 키만 유지

Identity 색·네이밍 변경에 영향받는 컴포넌트가 있다면 Figma 컴포넌트 라이브러리 측에서도 일괄 치환 필요. PINCH 코드 구현 시점에는 본 문서가 단일 진실의 원천(SSOT).
